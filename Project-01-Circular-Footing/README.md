# Project 01 – Settlement of a Circular Footing on Sand

## Overview

This project is based on the **PLAXIS 2D 2024.2 Tutorial Manual** and focuses on the settlement analysis of a circular footing resting on sandy soil using the Finite Element Method (FEM).

The objective was to understand the complete workflow of numerical modelling in PLAXIS 2D, including geometry creation, material definition, mesh generation, staged construction, and interpretation of analysis results.

---

## Software

- PLAXIS 2D 2024.2

---

## Analysis Type

- Settlement Analysis
- Finite Element Method (FEM)
- Static Analysis

---

## Soil Model

- Mohr-Coulomb

---

## Learning Objectives

- Creating the geometry
- Defining soil material properties
- Applying boundary conditions
- Mesh generation
- Applying foundation loads
- Running staged construction analysis
- Evaluating settlement and stress distribution

---

## Results

The analysis illustrates:

- Vertical settlement beneath the footing
- Stress distribution within the soil
- Deformation pattern of the foundation system

This project provided a practical introduction to finite element modelling of shallow foundations in PLAXIS 2D.
